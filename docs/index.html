When Does Auxiliary Classification Help Regression in Practice?

A Case Study in Arabic Dialectness Modeling: interactive demo

Estimates the Arabic Level of Dialectness (ALDi) of a sentence: a continuous score from 0 (Modern Standard Arabic) to 1 (fully dialectal). Our multi-task AraBERT system is trained with an auxiliary 7-bin classification head (Focal Loss); only the regression head is used at inference. It reaches a blind-test RMSE of 0.1275 on NADI 2024 Subtask 2, a new state of the art (previous best 0.1403).

Runs on CPU. Like this page, the model runs on CPU on your computer unless you have an NVIDIA GPU with CUDA set up. That's fine: it's a BERT-base model, so a sentence takes about 1–2 seconds on a normal laptop. The script picks the GPU automatically if one is available.
1
Install the requirements
Python 3.9+ recommended.
pip install torch transformers==4.39.3 huggingface_hub
2
Download the model
About 540 MB (model plus scripts) from the model page.
hf download asakr-ai/ALDi-Arabic-Dialectness-MTL --exclude "onnx/*" --local-dir aldi
cd aldi
3
Score a single sentence
Prints the ALDi score (0 = MSA, 1 = fully dialectal).
python predict.py --text "شو هالحكي يا زلمة"
4
Score a whole file (batch)
Results are written to a CSV with a new aldi_score column.
# CSV/TSV with a "sentence" column, or a .txt file with one sentence per line
python predict.py --input sentences.csv --output predictions.csv
5
Use it from Python
Import the same functions in your own code.
from predict import load_model, score

tokenizer, model, device = load_model("mtl_model")
print("Running on:", device)   # "cpu" unless you have a CUDA GPU

sentences = ["هذا الكتاب رائع جدا", "شو هالحكي يا زلمة"]
for sentence, s in zip(sentences, score(sentences, tokenizer, model, device)):
    print(f"{s:.3f}  {sentence}")
